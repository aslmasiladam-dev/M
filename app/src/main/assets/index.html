Production Readiness Checklist

Track your architecture compliance and production standards.

UI & State Handling
  • Use StateFlow / UiState data class for immutable screen states.
  • Collect state with collectAsStateWithLifecycle() in Compose.
  • Keep Composables stateless by passing callbacks up.
Domain & Logic
  • Zero Android framework imports in :domain module.
  • Use Cases have a single public operator fun invoke().
  • Return explicit Result<T> or custom Resource wrapper.
Data & Networking
  • Separate Network DTOs, Room Entities, and Domain Models with Mappers.
  • Repository single source of truth (Offline-First cache using Room).
  • Inject CoroutineDispatcher (Dispatchers.IO) via Hilt for testing.
